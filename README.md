# FIFA 14 (PS4) – PC Installer & Launcher

A one-click Windows installer and launcher that turns your own legally dumped PS4 copy of
**FIFA 14 (`CUSA00128`, EUR)** into a ready-to-play PC installation running on the
[shadPS4](https://github.com/shadps4-emu/shadPS4) emulator — **with the FIFA 14 fixes**: pitch
textures, replays, jersey names, correct bloom in day and night matches, and 60 FPS replays and
cutscenes.

> **No game files are included.** You must provide your own dumped PKG files or game folder.
> No PS4 firmware or system fonts are needed or included.

## Download

Get **`FIFA14.exe`** from the [Releases](../../releases) page. It is a single file — no Python,
no extra downloads.

## How to install

1. Run `FIFA14.exe`.
2. Choose the install folder (default `C:\Games\FIFA 14`, ~10 GB).
3. Pick your game source:
   * **PKG files** – base game PKG (required) and the **01.06 update PKG** (strongly recommended), or
   * **Extracted folder** – your `CUSA00128` folder (a `CUSA00128-patch` folder next to it is detected automatically).
4. Click **Start installation**. Extracting the PKG takes a few minutes.
5. Play with the **FIFA 14** shortcut on your Desktop.

## Launcher options

* Fullscreen (borderless) or windowed, window resolution (720p – 4K)
* Game language (English, Spanish, French, German, Italian, Portuguese, Russian, Japanese)
* **Brightness (gamma)** slider
* **60 FPS in replays and cutscenes** (on by default, needs update 01.06)
* FPS counter
* **Launch directly next time** – skips the launcher. Hold **Shift** while opening the shortcut to get the launcher back.
* Buttons to open the saves folder and the install folder

## Known messages (harmless)

* **"PS4 system fonts not found"**: FIFA 14 uses its own fonts, so text displays correctly.
* **Windows SmartScreen** "Unknown publisher": the executable is not signed. Click **More info → Run anyway**.
* Online modes do not work (EA's servers for FIFA 14 are closed).

## The fixes (technical)

The bundled emulator is the [FIFA 14 fix](https://github.com/danilenko22/shadPS4-FIFA14-fix) build
of shadPS4 (`b72489d` + [`patches/shadps4-fifa14-fix.patch`](patches/shadps4-fifa14-fix.patch)):

* **Replays:** `sceAppContentTemporaryDataMount` returns `/temp0`, so replays play instead of freezing.
* **Jersey names:** mip levels the GPU renders separately are merged correctly into their texture.
* **Pitch textures and per-stadium grass:** `readbacks_mode = 1` and linear image readbacks
  (written by the launcher to the game's config).
* **Bloom / glare:** real Vulkan occlusion queries. shadPS4 used to report ~50 million visible
  pixels per query, so every light glared; now the GPU counts the pixels actually drawn, and
  day and night/rain matches both look right.
* **Gamma** is saved between sessions (the launcher's slider writes it).
* **60 FPS replays and cutscenes:** a shadPS4 game patch
  ([`payload/game_patch/FIFA14-fix/FIFA14.xml`](payload/game_patch/FIFA14-fix/FIFA14.xml)) raises
  the replay/cutscene frame cap, applied in memory at startup (no game file is modified).
* **No PSN account prompt:** in offline mode the "signed out of PSN" system error dialog
  (`0x80550006`) is accepted automatically
  ([`patches/shadps4-offline-psn-error-dialog.patch`](patches/shadps4-offline-psn-error-dialog.patch)).

## Files and folders

```
C:\Games\FIFA 14\
├── FIFA14.exe                launcher (same file as the installer)
├── emulator\shadPS4.exe      portable shadPS4 (FIFA 14 fix build)
├── emulator\user\            emulator settings, logs, game patch and saves (home\1000\savedata)
├── game\CUSA00128\           your game files (+ CUSA00128-patch)
└── licenses\                 third-party licenses
```

**Uninstall:** delete the install folder and the Desktop shortcut (back up `emulator\user\home\1000\savedata` first if you want to keep your saves).

## Artwork

The installer banner is built by `make_banner.py` from `assets/cover_clean.jpg`, artwork provided
by the project author with all third-party marks removed (no game logo, rating badge, sponsor or
crest). The icon is original artwork generated by `make_icon.py`. Once installed, the launcher
shows the game's own title image (`sce_sys/pic1.png`) taken from the user's copy of the game.

## Building from source

Requires Python 3.10+ with `pyinstaller` and `pillow` (`build.bat` also generates the icon and the banner).

1. Put the third-party binaries in `payload\`:
   * `payload\emulator\shadPS4.exe` – shadPS4 commit [`b72489d`](https://github.com/shadps4-emu/shadPS4/tree/b72489d8c24e63fc56a29fe2c90120ab768a210d) built with all the patches in `patches\` applied
   * `payload\extractor\` – `pkg_extractor.exe`, `libc++.dll`, `zlib1.dll` from [ShadPs4Plus PKG Extractor v1.1](https://github.com/ZuanCrisp/shadPS4PlusPKGExtractor/releases/tag/v1.1)
   * `payload\licenses\` and `payload\game_patch\` are included in this repo
2. Run `build.bat`. The result is `dist\FIFA14.exe`.
